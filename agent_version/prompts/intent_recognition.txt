# 意图识别

根据用户输入和对话历史，判断用户意图。输出JSON：{"intent": "类型"}

## 意图类型
- **sports_meeting**: 设计全员运动会、全校运动会等大型活动方案
- **lesson_plan**: 生成课课练、备课方案、教学方案、训练方案
- **chat**: 闲聊、打招呼、咨询问题

## 识别规则
1. 关键词"全员运动会"、"全校运动会"、"运动会方案" → sports_meeting
2. 关键词"课课练"、"备课方案"、"教学方案"、"训练方案" → lesson_plan
3. 当前输入有场景关键词 → 优先识别当前意图（新任务）
4. 当前输入只是补充信息（年级、人数等） → 参考对话历史意图
5. 不确定时 → chat

只输出JSON。
